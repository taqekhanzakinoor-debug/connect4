# Rules for the AI Assistant

- Use only plain HTML, CSS, and JavaScript. No frameworks or libraries.
- Keep logic in `script.js`, styling in `style.css`.
- Follow `TASKS.md` in order, one task at a time.
- Keep functions small and name them clearly.
- Do not add features outside `FEATURES.md` without asking.
- Explain any non-obvious code with a short comment.
