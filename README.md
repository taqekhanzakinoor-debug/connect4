# Connect 4

A two-player Connect 4 game built with HTML, CSS, and JavaScript using a spec-driven "vibe coding" workflow.

## How to Play
1. Red goes first. Click a column to drop your disc.
2. Take turns. First to connect four in a row (any direction) wins.
3. If the board fills up, it's a draw.
4. Press **Restart** to play again.

## Run Locally
Open `index.html` in any browser. No install needed.
