# PRD: Connect 4

## Problem
People want a quick, familiar two-player game they can play in a browser with no setup.

## Goal
A web-based Connect 4 for two players on one device.

## Users
Friends playing together on one screen; beginners learning the vibe-coding workflow.

## Success Criteria
- Players alternate dropping discs into a 7x6 board.
- The game detects four in a row (horizontal, vertical, diagonal) and draws.
- The game can be restarted at any time.

## Out of Scope
Online multiplayer, accounts, sound. (AI opponent was added in v2.)

## v4: Board Game Hub
The project grew from one game into a **Board Game Hub** with six classic games: Connect 4, Tic-Tac-Toe, Othello, Checkers, Gomoku, and Chess. Each has 2-player mode and a computer opponent. A home page lists all games.
